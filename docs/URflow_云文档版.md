## 一、插件简介

URflow 是一款用于 Unity Editor 的**三阶贝塞尔曲线编辑器**，灵感来源于 After Effects 的 Flow 插件。它可以让动效设计师在 Unity 中直观地编辑 Animation Curve 的缓动曲线，无需手动调节 Keyframe 的切线参数。

### 核心功能

- 可视化贝塞尔曲线编辑器，支持拖拽控制点
- **控制杆可超出坐标轴框**，实现 Overshoot / Anticipation 效果
- **Shift + 拖拽水平吸附**，快速创建平滑缓动
- 从 Animation Window 读取 / 应用曲线，支持 Dopesheet 和 Curves 视图
- CurveGuard 在检测到权重模式被重置时尝试恢复已应用的曲线
- 37 个内置缓动预设：Standard 5 个、Penner 24 个、UI Motion 8 个
- 自定义预设保存、导入、导出
- 列表 / 网格视图切换
- Flow 风格深色主题，曲线渐变色显示

### 系统要求

- 包声明最低版本为 Unity 2022.3；仓库记录的测试版本为 2022.3.20f1，其他版本需在目标工程验证
- Editor Only（不影响运行时性能）

## 二、安装方法

### UPM 安装

打开 **Window → Package Manager → + → Add package from git URL**，填写：

```text
https://github.com/Ryancaoye/URflow.git#v1.0.3
```

省略 `#v1.0.3` 会跟随仓库默认分支。团队协作建议锁定 tag；`v1.0.2` 不包含后续 Apply / CurveGuard 修复。

### 离线安装

解压 `URflow_v1.0.3.zip`，将完整的 **URflow** 文件夹放到工程的 **Assets/URflow/**；或在 Package Manager 选择 **Add package from disk**，选中 `URflow/package.json`。保留 `.meta` 和图标，不要只复制脚本。

编译后通过 Window → URflow 或 Ctrl+Shift+E 打开。检查更新入口只打开 Package Manager。更新或代班后入口消失时，核对 Packages/manifest.json 的包依赖；开发版恢复步骤见末尾 2026年11月11日记录。

## 三、界面说明

### 3.1 曲线编辑区

窗口中央的深色区域是曲线编辑器，显示当前贝塞尔曲线的形状。

- **渐变曲线**：从青绿色 (#5EF0B0) 渐变到蓝色 (#0071FF)
- **橙色控制点**：P1（左下）和 P2（右上），可拖拽
- **黄色控制杆**：从起点/终点到控制点的连线
- **网格线**：4×4 网格辅助对齐
- **对角线**：线性参考线（linear）

### 3.2 参数输入

曲线下方有四个数值输入框：**X1、Y1、X2、Y2**，对应 CSS cubic-bezier(x1, y1, x2, y2) 格式。

- X1/X2 范围：0 ~ 1
- Y1/Y2 数值输入与 READ：-0.5 ~ 1.5，可实现一定程度的 Overshoot / Anticipation
- 拖拽代码允许 -2 ~ 3，但数值框会在界面更新时再次限制到 -0.5 ~ 1.5，更大范围不能视为稳定支持

上方文本框接受四个逗号分隔的数字，例如 `0.20, 0.00, 0.00, 1.00`。粘贴 CSS 参数时，去掉 `cubic-bezier(` 和末尾 `)`。

### 3.3 操作按钮

| 按钮 | 功能说明 |
|------|----------|
| **READ** | 读取第一条有效属性曲线的前两个选中关键帧 |
| **APPLY** | 在每条有效属性曲线上，按时间将选中帧两两相邻配对并应用 |
| **SAVE** | 保存当前曲线到 My Presets（弹出命名对话框） |

当前操作栏为 READ、APPLY、SAVE，没有单独的方向按钮或 Weighted 按钮。

### 3.4 预设浏览

下方预设区域有三个选项卡：

- **ALL** — 显示所有内置 + 用户预设
- **FAVORITES** — 收藏的预设
- **MY PRESETS** — 用户自定义预设，带导入/导出/删除操作栏

搜索栏右侧可切换**列表视图 / 网格视图**。收藏入口位于列表视图中每个预设左侧；内置分类为 Standard、Penner 和 UI Motion，当前没有 Material 3 分类按钮。

## 四、使用流程

### 4.1 基本工作流

1. 在 Animation Window 同一属性曲线上选择至少两个关键帧；首次使用建议选择时间相邻的两个帧
2. 打开 URflow 窗口（Window → URflow）
3. 点击 **READ** 读取当前关键帧的曲线
4. 拖拽控制点或选择预设调整曲线
5. 点击 **APPLY** 应用后，在 Unity 中预览动画

APPLY 自动设置 Broken / Free 和权重，通常无需手动设置 Weighted。可以同时选择多条属性曲线，但每条都需要至少两个选中帧。若中间还有未选中的帧，请逐段处理并检查结果；READ 不会汇总多段曲线。

### 4.2 快捷操作

| 操作 | 效果 |
|------|------|
| **拖拽控制点** | 调整曲线形状 |
| **Shift + 拖拽** | 锁定水平方向（P1 锁 Y=0，P2 锁 Y=1） |
| **应用预设** | 单击加载后点击 APPLY；双击存在事件处理问题，待 Unity 验证 |
| **单击预设** | 加载到编辑器预览 |
| **输入数值** | 在 X1/Y1/X2/Y2 输入框精确设置 |

### 4.3 保存自定义预设

1. 调整好满意的曲线
2. 点击 **SAVE** 按钮
3. 在弹窗中输入预设名称，点击保存或按 Enter
4. 预设自动保存到 MY PRESETS 选项卡

### 4.4 预设导入 / 导出

切换到 **MY PRESETS** 选项卡后，顶部出现三个操作按钮：

- **导入**：从 JSON 文件导入预设
- **导出**：将所有用户预设导出为 JSON 文件
- **删除**：删除选中的预设（弹出确认对话框）

导入采用追加方式，不自动去重。收藏和删除按名称识别，删除时会移除全部同名自定义预设；建议使用不同名称，并在搜索或切换选项卡后重新点选目标。

自定义预设保存在工程的 `ProjectSettings/URflow/UserPresets.json`，收藏保存在同目录的 `Favorites.json`。语言使用本机 `EditorPrefs` 的 `URflow_Language`。JSON 导出包含自定义预设，不包含独立的收藏名单。

## 五、常见问题

- **Q: APPLY 没反应？**
  - 确保 Animation Window 已打开，同一属性曲线上至少选中两个帧，且当前 AnimationClip 可编辑
- **Q: READ 读取的曲线不对？**
  - 先仅选一条属性曲线上的两个相邻帧。READ 只读第一组；等值端点返回默认线性参数，单侧 Weighted 或阶梯切线可能无法准确还原
- **Q: 想要 Overshoot 效果？**
  - 可将 Y1 设为负值或 Y2 设为大于 1；当前数值范围为 -0.5 ~ 1.5，Spring 和 Back In Out 的部分内置参数会被截断
- **Q: 预设文件保存在哪？**
  - 工程的 `ProjectSettings/URflow/UserPresets.json` 和 `Favorites.json`，备份或迁移工程时保留
- **Q: 拖动关键帧后会一直自动保护曲线吗？**
  - 本次编辑器会话中，经 APPLY 注册的曲线会被检查，仅在相关权重模式缺失时恢复。脚本重载或重新打开 Unity 后，保护登记不会保留；曲线本身仍保存在 AnimationClip 中
- **Q: 哪些操作需要额外检查结果？**
  - CurveGuard 按索引追踪，增删帧、跨帧拖动、Undo / Redo 和更换 Unity 版本后应检查结果。自动恢复会记录 Undo，但这些边界行为仍需验证

### 2026年10月31日批量尾帧检查

用户试用后确认关键帧移动符合需要，并提出在参数较多时一键列出尾帧与默认值的差异，再勾选要修改的属性统一对齐。本轮范围限定为 Animation 窗口当前一个动画片段的全部位置和缩放属性。

关键帧移动面板增加 Selected 和 Batch Scan 两种方式。Selected 保留原有选属性、首帧或尾帧对齐；Batch Scan 不要求预先选择属性，只比较每条位置或缩放曲线的最后一个关键帧与未受动画驱动的静态布局值。

#### 批量检查操作

关联当前界面的场景实例与 Animation 窗口，打开底部 Move 工具，切换 Batch Scan 后自动扫描当前片段；底部 Rescan 可重新扫描。列表按对象路径分组，显示属性轴、动画尾帧、默认值和差值；尾帧指各条曲线的最后一个关键帧，可能早于整个片段的结束时间。

Differences only 默认只看差异，且不勾选任何属性。可以搜索对象或属性，逐项或按对象组勾选；Select Visible 选择当前筛选下可处理的差异项，Clear All 取消全部勾选。数值不一致只表示差异，退场等动画可能故意停在默认位置之外，是否对齐由使用者决定。

筛选保留隐藏项目的勾选，并提示筛选外已选数量；底部 Apply (N) 显示全部已选总数。重新扫描、切换比例模式、Undo/Redo 刷新及重新进入 Batch Scan 会清空勾选。应用前核对总数，统一调整明确勾选的属性。默认整体平移，Proportional adjustment 使位置和缩放按比例调整。

应用后整条曲线的全部关键帧一起变化，使尾帧对齐默认值；不会只改最后一帧。一次 Undo 撤销本批修改，一次 Redo 重做。未勾选属性和其他动画片段不在批量修改范围内。

#### 无法处理的项目

已经一致的属性无需勾选。找不到对应对象、静态值仍受动画预览或布局驱动、以及比例基准为零却需要对齐到非零默认值的项目保留在列表中并显示原因，不能勾选；这些未勾选项目不会阻止其他有效项目应用。旋转、透明度与对象引用轨道不在本轮扫描范围。

读取默认值时暂时退出当前 Animation 预览，再恢复预览和原时间；录制保持关闭。应用前重新核对当前对象、片段、属性集合，以及已勾选曲线和静态值；发生变化时要求重新扫描，避免使用过期结果。零倍率或负倍率继续显示归零或反转提醒。

### 2026年11月7日拉伸布局位置与尺寸对齐

用户发现垂直拉伸的 RectTransform 对齐后，默认 Top 50、Bottom 80 变成 Top 35、Bottom 65。本轮修复此前只纳入位置而遗漏 Size Delta 动画的支持范围；当前关键帧移动还需要考虑尺寸曲线。

#### 拉伸边距的关系

Top / Bottom 或 Left / Right 由 Anchored Position、Size Delta 和 Pivot 共同决定。Y 轴 Pivot 为 0.5 时，Top 50、Bottom 80 对应 Anchored Position Y 为 15、Size Delta Y 为 -130；位置对齐为 15 而尺寸仍为 -100，就会得到 Top 35、Bottom 65。截图中的 80 和 -160 未确定采样时间，不能据此声称它们是错误结果的同一尾帧。

#### 检查与勾选方式

统一页面增加 RectTransform 的 UI Size X / Y（Size Delta）曲线，和 UI Pos X / Y 一起显示基准帧值、静态默认值及差值。它们是尺寸偏移，不是 Scale。首帧、尾帧、整体平移及比例选项沿用当前操作；尺寸差异使用与位置相同的 0.0001 绝对容差。

拉伸轴的位置与尺寸都有差异时，请明确勾选同一对象、同一轴的两项再应用。例如垂直拉伸应同时勾选 UI Pos Y 和 UI Size Y。缺少配对差异项时整次应用拒绝写入并显示提示，不自动扩大勾选、不修改筛选外未勾选项。Only Animation selection 也不会暗中扩选配对。

同轴配对已经一致时可以只改仍有差异的一项；没有配对动画轨道时使用静态值，不创建新曲线。非拉伸轴的位置与 Size Delta 允许独立处理。其他轴、其他对象和未勾选曲线保持原状；一次 Undo / Redo 仍对应整批写入。

比例模式对 Size Delta 的原始数值计算倍率。实际宽高还包含父矩形与锚点跨度，因此这不代表界面的实际宽高按同一比例缩放。负 Size Delta 是合法布局数值；比例基准为零而目标非零时仍拒绝计算。曲线时间、关键帧数、切线模式、Broken、权重及 wrap mode 保留。

#### 布局驱动和过期结果

锚点或 Pivot 自身带有动画时，本轮不支持完整位置与尺寸对齐，相关行显示原因并禁止应用；Scale 行仍按原规则处理。自动布局驱动的尺寸与位置不作为可靠静态默认值。扫描后锚点、Pivot、勾选曲线或默认值发生变化时要求重新扫描，应用前在暂停当前预览的状态重新核对同轴配对。

### 2026年11月12日曲线画布与应用范围修复

APPLY 只修改所选关键帧区段朝内的切线方向。例如选中前三帧中的前两帧，修改第一帧右侧和第二帧左侧，保留第二帧右侧至第三帧的曲线。单侧应用按当前方向设置处理；区段外的切线、权重及切线模式继续保留。CurveGuard 只保护登记的方向；Undo 或 Redo 后清空旧登记，避免恢复已撤销的曲线，需要重新 APPLY 才建立保护。

曲线预览使用固定画布，Logo、参数和 APPLY 分别占据各自区域。普通曲线沿用 Y=0～1；控制点超过这个范围时，自动扩大显示范围，同时容纳两个端点、黄色控制点及曲线。0 和 1 的参考线标明尺度；视图缩放只改变显示，不修改曲线参数。拖动采用稳定尺度，接近边缘时扩展，松手后平滑适配。

手动输入 Y 与原有拖动范围统一为 −2～3。READ 保留有限的原始 Y 值，超过该范围也可显示；横向拖动保持 Y，纵向拖动范围包含该次手势的起始值，未编辑的 READ 或预设值不再被重绘截断。关键帧移动改为 Offset / Ratio 两个互斥按钮，中文显示平移 / 比例，默认平移；点击当前模式保持勾选，切换模式清空勾选并重新扫描。平移和比例算法及零基准限制沿用现有规则。

独立 Unity 2022.3.56f1c1 中，18 份源码严格编译，以及 APPLY、CurveGuard、Undo/Redo、READ 的 908 项断言、模式按钮与数学的 32 项检查、画布拖动与显示的 148 项检查通过；四类离屏曲线图已检查。制作场景和真实鼠标操作手感仍待试用，边缘扩展时控制点可能稍离开光标，但参数连续。源码已保存于 feature/v1.0.4 的 0b9ee6e、c481741、6bd25b9、975d2a7；目标 v1.0.4 未发布，正式版本字段仍为 1.0.3。
