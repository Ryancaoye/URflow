# URFlow v1.0.4 关键帧移动试用说明

这是 v1.0.4 开发分支的关键帧移动功能，包含 Selected 属性对齐与 Batch Scan 批量尾帧检查。稳定目录与正式标签仍为 v1.0.3，开发包的正式版本字段尚未更新；不要仅凭窗口页脚版本判断是否加载了新功能，应确认开发包路径并看到“关键帧移动”入口。

## 在现有项目工程中使用

本功能可以在正常 Unity 项目中使用。独立工程用于开发时的编译、曲线写入和撤销验证，不是使用要求。

根据项目当前的安装方式更新，项目内只保留一份 URFlow：

- 原先复制到 `Assets`：先把旧插件留一份副本在 `Assets` 外，再将开发目录 `D:\插件\URFLOW\6-开发\URflow-v1.0.4\Editor` 的内容更新到项目原 URFlow 的 `Editor` 目录，保留 `.meta`。这一版是在原代码上新增模块，不需要另建一个 URFlow 文件夹。
- 原先通过 Package Manager 安装：将原 URFlow 的包依赖改为开发目录的本地包。可在 Package Manager 的 `+ > Add package from disk` 选择 `D:\插件\URFLOW\6-开发\URflow-v1.0.4\package.json`。若 `Assets` 里还有复制安装的旧版，先把它移出 `Assets`，避免重复程序集。

等待 Unity 编译后，打开 `Window > URflow`，看到预设下方“关键帧移动”入口即可。首次试用可复制一份现有 `.anim` 并临时关联该副本，确认首尾对齐及 Undo/Redo 的结果，再用于制作中的动画。

开发版仍有完整界面和视觉验收待完成，已验证范围见开发记录。不要把 `Tests~` 内的验证脚本导入制作工程；它们只用于开发验证。

## Selected 属性对齐

1. 在没有 Animation 预览驱动时，把场景实例的位置或缩放改为想要的静态布局值。
2. 关联这个实例的 Animation 窗口，选择要处理的属性行，例如 Position X、UI Position Y 或 Scale X。选择属性组会包含该组的轴；只选一个关键帧，也可以识别它所属的属性。
3. 打开 `Window > URflow`，点击底部 Move 工具，选择 Selected。
4. 选择首帧或尾帧。默认是尾帧、整体平移；需要围绕数值 0 按比例调整时勾选“按比例调整”。位置和缩放均可使用两种模式。
5. 核对只读预览中的属性、基准值、默认值、偏移或倍率及调整后的首尾值。换了对象、动画、属性选择或静态值后，点击“刷新”；返回 URFlow 窗口也会刷新已打开的面板。
6. 点击“应用移动”。对应属性的所有关键帧一起改变，其他属性保持原值。一次 Undo 撤销这次移动，一次 Redo 重做。
7. 关闭按钮或 Escape 返回原曲线界面；原曲线参数、预设筛选与滚动状态保留。

## Batch Scan 批量尾帧检查

1. 将当前 Animation 窗口关联到界面的场景实例和本次要处理的动画片段，不需要选择属性行或关键帧。
2. 打开底部 Move 工具，切换 Batch Scan 后自动扫描当前片段的全部位置和缩放属性；需要更新结果时点击 Rescan。
3. 按对象分组查看动画尾帧、静态默认值和差值。这里的尾帧是每条属性曲线自己的最后一个关键帧，可能早于动画片段的结束时间。
4. Differences only 默认只显示差异且不勾选任何项。可搜索对象或属性，再逐项、按对象组勾选，或使用 Select Visible 选择当前筛选下可处理的差异项。差异不是错误判定，退场动画可能有意停在其他位置。
5. 筛选保留已勾选项目，并提示筛选外已选数量；底部 Apply (N) 包含全部已选项。Clear All 取消全部勾选，重新扫描、比例模式变化、Undo/Redo 刷新及重新进入 Batch Scan 会清空勾选。
6. 默认整体平移；按需勾选 Proportional adjustment，位置和缩放都可以按比例调整。核对总数后点击 Apply (N)，明确勾选的整条曲线统一尾帧对齐；一次 Undo/Redo 对应整批修改，应用后自动重扫并显示修改数量。

已经一致的属性不需要修改。缺失目标、布局或其他预览驱动、无效数据、比例零基准等项目显示原因并禁止勾选，不阻止有效勾选项应用。扫描不写入动画。应用前重新核对当前对象、动画、属性集合、勾选曲线和默认值；过期结果必须重新扫描。

## 两种规则

- 整体平移：`-100 → 100`，尾帧默认值 `200`，得到 `0 → 200`；有限切线斜率和数值差保持。
- 按比例调整：相同位置曲线得到 `-200 → 200`；缩放 `0 → 1`、尾帧默认值 `1.5`，得到 `0 → 1.5`。动作幅度会改变，有限切线斜率同乘倍率。

两种模式都保留时间、关键帧数量、切线模式、Broken、权重及 wrap mode。首/尾指整条曲线的最早/最晚关键帧。

## 首版边界

- 首版支持 Transform/RectTransform 的本地位置、UI anchored position 与本地缩放；旋转和透明度不在本版范围。
- Selected 模式下，若属性行与关键帧选择范围互相冲突，先清理旧选择，再重新选具体属性并刷新，避免移动到错误范围。
- Selected 模式下，任何选中属性无效时整次不修改；Batch Scan 只应用工具列表中明确勾选的有效差异项。过期结果须刷新或重新扫描后再应用。
- 比例基准为 0、默认值非 0时不能计算倍率。二者都为 0时已对齐，不产生修改。零倍率与负倍率在面板中明确提示，应用后分别归零或反转数值。
- 自动布局驱动的目标轴、其他动画预览驱动、运行模式和不可编辑动画会提示原因。
- 读取默认值时退出当前 Animation 窗口自身预览，随后恢复普通预览及原时间；录制状态保持关闭，避免自动增加关键帧。
