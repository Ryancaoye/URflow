## 操作步骤

1. 在没有 Animation 预览驱动时，把场景实例的位置或缩放改为想要的静态布局值。
2. 关联这个实例的 Animation 窗口，选择要处理的属性行，例如 Position X、UI Position Y 或 Scale X。选择属性组会包含该组的轴；只选一个关键帧，也可以识别它所属的属性。
3. 打开 `Window > URflow`，点击预设下方的“关键帧移动”入口。
4. 选择首帧或尾帧。默认是尾帧、整体平移；需要围绕数值 0 按比例调整时勾选“按比例调整”。位置和缩放均可使用两种模式。
5. 核对只读预览中的属性、基准值、默认值、偏移或倍率及调整后的首尾值。换了对象、动画、属性选择或静态值后，点击“刷新”；返回 URFlow 窗口也会刷新已打开的面板。
6. 点击“应用移动”。对应属性的所有关键帧一起改变，其他属性保持原值。一次 Undo 撤销这次移动，一次 Redo 重做。
7. 关闭按钮或 Escape 返回原曲线界面；原曲线参数、预设筛选与滚动状态保留。

## 两种规则

- 整体平移：`-100 → 100`，尾帧默认值 `200`，得到 `0 → 200`；有限切线斜率和数值差保持。
- 按比例调整：相同位置曲线得到 `-200 → 200`；缩放 `0 → 1`、尾帧默认值 `1.5`，得到 `0 → 1.5`。动作幅度会改变，有限切线斜率同乘倍率。

两种模式都保留时间、关键帧数量、切线模式、Broken、权重及 wrap mode。首/尾指整条曲线的最早/最晚关键帧。

## 首版边界

- 首版支持 Transform/RectTransform 的本地位置、UI anchored position 与本地缩放；旋转和透明度不在本版范围。
- 若属性行与关键帧选择范围互相冲突，先清理旧选择，再重新选具体属性并刷新，避免移动到错误范围。
- 任何选中属性无效时，整次不修改。过期预览也须刷新后再应用。
- 比例基准为 0、默认值非 0时不能计算倍率。二者都为 0时已对齐，不产生修改。零倍率与负倍率在面板中明确提示，应用后分别归零或反转数值。
- 自动布局驱动的目标轴、其他动画预览驱动、运行模式和不可编辑动画会提示原因。
- 读取默认值时退出当前 Animation 窗口自身预览，随后恢复普通预览及原时间；录制状态保持关闭，避免自动增加关键帧。
