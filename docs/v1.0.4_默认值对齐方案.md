# v1.0.4 默认值对齐方案

日期：2026-10-29。状态：需求讨论与设计，尚未开始功能实现或 Unity 运行验证。

## 用户已确认的需求

- 交互调整 UI 布局数值后，一键让动画首帧或尾帧对齐新的默认值。
- 默认值是当前界面实例没有受到动画驱动时的静态布局值，不是动画预览采样值，也不以 Prefab 资源值替代。
- 只作用于 Animation 窗口中用户选中的属性曲线；该属性的全部关键帧一起调整，不只处理选中的关键帧。
- 首版支持位置与 Scale 缩放属性，透明度暂不加入。
- 默认采用整体平移。增加“按比例调整”勾选项，勾选后改用比例模式。
- 位置和缩放都支持这两种模式，不能把比例模式限制为仅 Scale。
- 可以借鉴用户提供的 Anim_KeyValueOffset.cs 的偏移思路、窗口预览控制及 Undo 结构，但要按本需求调整范围与可靠性。
- 用户已确认集成在同一个 URFlow 窗口，预设列表下方、原设置/版本栏上方设置统一的工具图标区；不另开独立工具窗口。
- 已确认采用 Motion4 式的两类入口：简单工具点击图标直接执行（Instant）；具有复杂选项的工具点击图标后，从底部向上展开同窗口详细面板（Panel），关闭面板返回原曲线编辑视图。

## 对齐行为

对每条选中的属性曲线独立处理。首/尾分别指该曲线最早/最晚关键帧，不以当前游标或局部选中帧为端点。对齐值来自对应对象、对应属性的静态默认值。

### 默认：整体平移

- delta = 静态默认值 - 对齐帧原值。
- 所有关键帧 newValue = oldValue + delta。
- 切线斜率保持，动作幅度、关键帧间数值差及缓动形状保持。

例如位置 X 为 -200 → 0，默认 X 改为 50；尾帧对齐后为 -150 → 50。

### 勾选：按比例调整

- factor = 静态默认值 / 对齐帧原值。
- 所有关键帧 newValue = oldValue × factor，围绕数值 0 缩放。
- 有限的 in/out tangent 同乘 factor；否则不能保留对应的缓动形状。
- 时间、权重和切线模式保持；动作幅度随 factor 变化，不能声称幅度不变。
- Infinity 阶梯切线需保持其模式，不直接进行会产生 NaN 的乘法；真实写入行为需要 Unity 验证。

例如 Scale 为 0 → 0.6 → 1，默认 Scale 改为 1.5；尾帧比例对齐后为 0 → 0.9 → 1.5。
例如位置 X 为 -100 → 100，默认 X 改为 200；平移结果为 0 → 200，比例结果为 -200 → 200。

每个属性独立计算 delta 或 factor。X/Y 可以得到不同倍率，因此不能称为整组位置使用一个统一倍率；二维运动路径的角度也可能变化。只选 X 时 Y 不变。

两种模式均保留关键帧数量、时间、in/out weight、weightedMode、切线模式、Broken 状态及曲线 wrap mode。比例模式按上述规则改变有限切线斜率。不得复用现有 READ → APPLY 重建曲线，不归一化、不截断新值。

## 比例模式边界

- 对齐帧原值为 0、默认值非 0：无法计算倍率，明确提示对应属性；不能自动切回平移、换另一帧或修改该曲线。
- 对齐帧原值与默认值均为 0：已经对齐，无修改，也不新增 Undo。
- 计算结果包含 NaN 或 Infinity：拒绝写入并提示。
- 默认值为 0、对齐帧非 0时，factor 为 0，会消除该属性的动画变化；负倍率会反转位置运动或改变缩放符号。这两类结果的产品提示方式仍待讨论。
- 多选中存在无法处理的属性时，建议预检查并整次不写入，避免静默部分成功；最终失败策略仍待确定。

## 建议的操作与模块边界，待讨论后实施

- 选中属性即可识别目标，不要求选两个关键帧。
- 提供首帧对齐默认值、尾帧对齐默认值及默认未勾选的按比例调整选项。
- 一次操作对应一次 Undo / Redo；已对齐时重复点击不产生修改。
- 普通预览开启时先缓存 clip、root、bindings、时间和模式，再退出当前 Animation 窗口预览读取静态值；操作后可恢复普通预览和时间，不自动恢复录制。
- 无选择、无法找到对应对象、只读曲线或无法可靠读取静态值时明确提示。
- 对齐功能放进独立模块目录，模块 UI、纯计算和 Unity 读写分离；主窗口只通过薄绘制入口接入，并统一管理工具图标、面板打开/关闭及面板空间；模块自行管理参数、计算和 Unity 读写，不依赖主窗口当前贝塞尔参数、预设或拖拽状态。
- 保持已有 READ/APPLY 规则；不要全局清空 CurveGuard 或用主面板参数重登记新曲线。
- 写入前生成并验证修改计划；写入仅覆盖已选择的绑定，失败恢复仅限本次修改。
- 独立模块仍共享 Unity 环境与动画资产，不能保证任意错误完全不影响其他功能；需要验证编译、预览、Undo 和 CurveGuard 的共同使用。
- 统一工具图标区和 Instant/Panel 交互已确认；图标数量与样式、详细面板排布、候选快捷入口及比例特殊结果提示仍需看草图讨论。默认值对齐因包含首/尾选择和比例选项，可采用 Panel 型入口。

## 同窗口工具区与面板的实现建议，尚未制作或验证

统一底部工具图标区及 Instant/Panel 交互已由用户确认；下面的具体模块、布局和异常处理方式仍是实现建议，不代表插件已经实现或运行验证通过。

- 主界面保留原曲线编辑与操作区、预设筛选和列表。统一工具图标网格固定在预设列表下方、原设置/版本栏上方，不跟随预设内容滚动；预设列表填充宿主分配的剩余高度并独立滚动。
- Instant 工具点击图标即执行预先明确的简单操作。Panel 工具点击图标只打开详细面板，由用户确认面板选项并执行；面板从底部向上展开，关闭后回到原曲线视图。开关面板本身不修改动画数据，原曲线和预设编辑状态应保留。
- 默认值对齐含首/尾选择和默认未勾选的按比例调整选项，可作为 Panel 型工具。静态默认值、偏移量或倍率可采用只读预览供用户核对；当前没有要求手动编辑默认值或倍率，不把它们设计成可编辑参数。
- 草图中的“首帧平移”和“尾帧平移”仅作为 Instant 型候选快捷图标展示；是否正式增加这两个额外入口仍待用户确认，不能视为用户已经要求的固定功能。草图中的“默认值对齐”用于展示复杂面板入口。
- 宿主统一管理图标网格、当前打开的工具、面板打开/关闭及面板空间，仅调用模块绘制入口和必要的动作入口。各模块独立管理自己的 UI 参数、运算及 Unity 选取、静态值读取、Undo 和写入，不把业务逻辑堆进旧 OnGUI 或 READ/APPLY，也不需要为首版搭建完整插件框架。
- 现有预设列表使用 ExpandHeight(true) 占用剩余空间，没有手写窗口总高度减各区的算法。接入时由宿主预留固定图标区并分配展开面板空间，再让列表填充余量；面板具体高度与空间变化按草图讨论，保持原列表、搜索及切换规则。
- 模块布局使用对称的 GUI/GUILayout scope，并恢复 GUI.enabled、颜色和裁剪等共享状态；普通运行异常在模块区域提示，保持宿主布局稳定。ExitGUIException 必须继续抛出交由 Unity 结束 GUI，不能被通用异常处理吞掉。必要时将业务操作排到当前 GUI 绘制结束后执行。
- 普通主界面和保存预设弹窗的禁用背景两条绘制分支使用一致的工具区与面板布局；弹窗背景继承外层禁用状态。设置页仍使用原页面，不显示工具区或工具面板。
- 同窗口的模块边界可以减少耦合，但不能保证任意异常都不影响宿主；AnimationClip、Undo、预览与 CurveGuard 仍是共享资源，需要限制写入范围、完整预检查及失败恢复。

## 技术核对与证据边界

本次只读审查了仓库、参考脚本及 Unity 官方 2022.3 源码，没有运行 Unity 测试。

- 当前 URflowAnimHelper 主要识别同曲线至少两帧的关键帧选择；新模块需独立获取选中属性，不改变旧方法行为。
- AnimationWindowState 提供 activeRootGameObject、selectedHierarchyNodes 与 StopPreview；使用当前窗口自己的 driver 退出预览。
- 无参数 AnimationMode.StopAnimationMode 使用 DummyDriver，不能可靠替代窗口的 StopPreview。
- 退出预览后可用 AnimationUtility.GetFloatValue(root, binding, out value) 读取属性；是否准确恢复到交互最新布局仍需动态验收。
- 参考脚本的反射字段链与本机 Unity 2022.3.56f1 对应；但停止预览后缺少成功确认，且只移动选中的 key。
- 参考脚本会重新设置切线模式，可能重算切线；其 GUI 纹理创建、结果统计及非数值位移属性范围也需调整，不能原样作为本功能实现。
- Play Mode、其他持续驱动和自动布局需要防护或验证。旋转、对象引用、布尔/离散轨道不属于本次支持范围。

## 计划的验收场景

1. 在普通状态和 Animation 预览中，位置及 Scale 的首/尾对齐都读取最新静态值。
2. 位置 [-200, -80, 0]、默认值 50，平移尾帧对齐得到 [-150, -30, 50]。
3. Scale [0, 0.6, 1]、默认值 1.5，比例尾帧对齐得到 [0, 0.9, 1.5]；有限切线乘 1.5。
4. 位置 [-100, 100]、默认值 200，分别得到平移 [0, 200] 与比例 [-200, 200]。
5. X 比例为 2、Y 比例为 3时，各自处理；未选属性、其他对象及 clip 不变。
6. 普通、加权及阶梯曲线的时间、权重、模式符合规则；平移斜率不变，比例有限斜率同倍调整。
7. 零值基准、非有限结果、零倍率与负倍率的提示和数据保护符合最终确定的规则。
8. 有无 CurveGuard 登记、等待编辑器更新及 Undo/Redo 后，结果与预览状态仍正确。
9. 一次 Undo 完整恢复，一次 Redo 重做；已对齐时重复点击无变化。
10. 新工具与原曲线编辑同时使用，原 READ/APPLY、预设及面板状态行为保持。
11. Instant 点击执行已定义动作；Panel 点击只打开详细面板，关闭返回原曲线视图且不额外修改动画数据，宿主布局和原编辑状态保持。候选快捷图标仅在最终确认纳入范围后验收。

以上是待执行的验收计划，不是已通过的测试结果。
