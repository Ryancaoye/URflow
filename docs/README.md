## 生成 Word

在本目录安装依赖后执行：

```powershell
npm install
npm run build
```

也可使用 `node create_guide.js "输出目录"` 指定位置。脚本默认输出到 docs；运行整理目录的 `_生成脚本/create_guide.js` 时，默认输出到上一级 `3-使用说明`。旧版 Word 不会被覆盖。

## 同步流程

1. 以源码核对功能，区分已修复问题和仍待验证的限制。
2. 同步仓库 README、中文 Markdown 和 Word 生成脚本；只改文档时不提升插件版本。
3. 生成 Word，逐页检查表格、字体和换页。
4. 同步到本地整理目录的 `3-使用说明`，文档记录同步到 `4-更新日志`。
5. 检查 Git 差异后按项目流程提交。文档校正不代表已执行 Unity 回归测试。
